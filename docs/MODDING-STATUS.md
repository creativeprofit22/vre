## Known limits

- **Rust helper internals** (`voyager-dictation`, `voyager-video`, `voyager-daw`, `voyager-resource-monitor`, `voyager-launcher`) and other native code (`Voyager.exe`, `.node` addons, `api-models.exe`'s Bun runtime) are not changed. Mods can intercept, rewrite or replace their launches, but not their code.
- **Remote services stay remote.** Moda cloud models, credits, billing and third-party provider accounts can't be emulated locally. With sign-in removed, AI generation in the copy needs your own API keys (Settings > Accounts > Add key; keys are local, not sign-ins) or a local model server. The copy doesn't set one up.
- **Agent CLIs keep their own logins.** Codex and Claude Code run as separate programs with their own sign-in. The copy blocks the browser step, so those providers stay unavailable until you give them API keys yourself.
- **Hot reload covers renderer mods only.** Main, node and helper mods and `patches.json` take effect on the next launch (patches need `mod rebuild`).
- **`patches.json` targets `app.asar` and `server.asar`.** Loose JS under `resources/voyager/` (media service, CLI) is changed at runtime through node mods, not build-time patches.
- **Renderer mods** run in top-level windows only (not webviews or background pages). The UI sign-in hider matches English and Spanish labels.
- **Pinned to Voyager 0.1.98.** After an update, `mod rebuild` re-checks every patch and fails loudly if a match count changed. Glob file names absorb renamed bundles; changed code still needs a patch edit.
- **Electron fuses are never flipped.** If a future Voyager turns on `EnableEmbeddedAsarIntegrityValidation` or `OnlyLoadAppFromAsar`, the build stops with a clear error instead of modding.
- **Windows only.** The copy, launch flow and evidence are Windows-specific.
- **Installer script recovery** shows NSIS user variables as `$_N_` (names aren't stored in the binary), and custom installer page UI is not rendered.
- **Per-channel sender checks** are static and look one call level deep; "unchecked" means no check was seen, not proof there is none.
